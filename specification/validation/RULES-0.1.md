# AFS Validation Rules 0.1

| Rule | Severity | Requirement |
|---|---|---|
| AFS001 | Error | Required repository path is missing |
| AFS002 | Error | ADR file name does not match `ADR-NNNN-slug.md` |
| AFS003 | Error | ADR number is duplicated |
| AFS004 | Error | ADR heading is missing or its number differs from the file name |
| AFS005 | Error | Required ADR metadata is missing |
| AFS006 | Error | ADR status is not an allowed value |
| AFS007 | Error | ADR date is not a valid `YYYY-MM-DD` date |
| AFS008 | Error | Required ADR section is missing |
